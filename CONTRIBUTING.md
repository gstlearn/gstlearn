### How to Contribute

If you want to contribute to gstlearn you need a GitHub account and then, you can either:
  * Create a GitHub [issue](https://github.com/gstlearn/gstlearn/issues) or, *preferably*,
  * Submit a Pull Request (PR) on GitHub from your forked repository.

Before submitting the PR, it is strongly recommended to:
  * Setup the development environment on your computer (see [README.md](README.md)),
  * Execute non-regression tests,
  * Install and configure [pre-commit](https://pre-commit.com) (to automatically format your code before a commit).

The PRs are reviewed and merged by the Core Team.
